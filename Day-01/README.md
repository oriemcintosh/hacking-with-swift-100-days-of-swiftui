# Day 01 — Variables, Constants, and Strings

This folder covers the opening lesson from [100 Days of SwiftUI](https://www.hackingwithswift.com/100/swiftui/1).

## Summary

Day 1 introduces the Swift fundamentals used throughout the course:

- `var` vs `let`
- `String`, `Int`, `Double`, and `Bool`
- String interpolation
- Basic type safety and simple values

## Exercise notes

The Day 1 exercises are lightweight practice snippets rather than a full app project. The goal is to get comfortable declaring values, reading types, and combining text with variables.
