# 100 Days of SwiftUI — Learning Tracker

This repository is my personal workspace for working through the "100 Days of SwiftUI" tutorials from Hacking with Swift (https://www.hackingwithswift.com/100/swiftui). I will use this repo to track exercises, projects, notes, and experiments while going through the course. 

## Goals

- Follow the course tutorials and complete the projects and challenges.
- Build small, focused demo projects for each day/chapter.
- Keep notes on important SwiftUI concepts, patterns, and APIs.
- Experiment with alternative implementations and refactors.

## Suggested Schedule

- Tackle 3–5 short lessons per week (adjust as needed).
- Mark progress in the repo by adding a folder per day (e.g., `Day-01`) and commit regularly.
- Use branches for larger experiments (e.g., `day-12-animations`) and merge when stable.

## Repository Structure (suggested)

- `Day-XX/` — One folder per day, containing project code and notes.
- `Notes/` — Text files with summarized concepts, tips, and examples.
- `Resources/` — Links, screenshots, and reference material.
- `README.md` — This file.

Example:

- Day-01/
  - README.md — short summary of what I learned that day
  - Project/ — Xcode project or Swift playground files

## How I’ll Use This Repo

- Create a new folder for each day and commit work there.
- Keep commit messages short and descriptive (e.g., "Day 05: completed layout exercises").
- Use GitHub issues or the repository wiki to track research and bigger tasks or project ideas.
